# Clean-room and data attribution note

CohortLens Reliability Audit is an original portfolio learning system. I studied high-level ideas from public reliability, data-quality, and model-assessment projects, but did not copy code, UI layouts, metric implementations, assets, datasets, or documentation.

The built-in reference slice transcribes selected rows from the [UCI Wine Quality dataset](https://archive.ics.uci.edu/dataset/186/wine+quality), attributed to Cortez et al. (2009). UCI lists the dataset under CC BY 4.0. The app's score rule, interfaces, cohorts, tests, and documentation are independently authored. The small reference slice is included only to make local calculations reproducible; it is not a model-training dataset in this repository.
